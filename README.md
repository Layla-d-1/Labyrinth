# LABYRINTH
## C based terminal game.

This program accepts two commandline arguments, one of them being a txt file of a game map, to configure the game.
Program reads file, stores ina 2D array and prints map to terminal, with player, enemy and treasure. 

# OBJECTIVE
#### Players must collect treasure using the A W S D  keys. For every step the player takes, the enemy takes 2x the steps. If the player collects the treasure,
the enemy will react by taking 3x the players movements. Players must collect the treasure and reach the goal to win the game. If enemy catches on to the player before that. Player will
lose the game.
